# Glimpse

Glimpse — seeded from the Lovable spin-a-word-wheel board.

This is a seed of the wheel-of-fortune style game show board (animated letter/box reveal). No UI redesign and no new game logic yet — scaffolding only.

## Development

```sh
bun install
bun run dev
```

Or with npm:

```sh
npm i
npm run dev
```
